# 架构说明 — 共同设施 + 功能域

> 这份文档对应 `src/` 在 2026-09-17 的结构重组。目的只有一个：**看清楚东西在哪、改一处不用翻十个文件。**

## 一、分层规则

两侧半边（host / client）用同一套规则，三种角色分工明确：

| 角色 | 目录 | 职责 | 允许依赖 |
|---|---|---|---|
| **共同设施** | `src/shared/`、`src/client/shared/` | 跨域原语：路径、fs、解析、HTTP 管道、线格式类型 | 只向下依赖 node/外部包，**不认识任何功能域** |
| **功能域** | `src/features/<域>/`、`src/client/features/<页签>/` | 一个工具族的完整垂直切片：自己的状态 + 自己的管理逻辑 + 自己的路由 | `shared/` + 自己域内文件；**不 import 兄弟域的内部文件** |
| **组合根** | `src/index.ts`、`src/routes.ts`、`src/setup.ts`、`src/client/index.ts` | 把各域装到一起：构造、拼表、注册 | 任意 `shared/`、任意域**的桶文件（index.ts）** |

判断一个文件该放哪，只问一句：**「换掉 skills 这个工具族时，它要不要动？」**
要动 → 进 `features/skills/`；不动 → 进 `shared/`。

## 四、怎么改（三种典型场景）

**加一个工具族**（比如 env 管理）
1. 建 `src/features/env/`：`manager.ts` + `routes.ts` + `index.ts`
2. 线的类型加进 `src/shared/protocol/env.ts`，路径加进 `api-paths.ts`，两者在 `protocol/index.ts` 出桶
3. `src/routes.ts` 加一行 `...envRoutes(env)`
4. `src/index.ts` 构造 engine 并传进 `makeRoutes`

**改一个功能域的内部实现**
只动 `src/features/<域>/` 里的文件。`shared/` 与其它域不需要看一眼 —— 这是这套分层买到的东西。

**加一个页签**
1. 建 `src/client/features/<页签>/`：`XxxPanel.tsx` + `useXxx.ts`
2. `ManagerShell.tsx` 挂上，`shared/constants.ts` 的 `TABS` / `TAB_LABELS` 加一项
3. `shared/locales.ts` **中英两份都加键**

## 五、两条硬约束（踩过才知道）

### 1. 目录 import 不被解析，必须写全路径

`moduleResolution: bundler` **不会**把 `from '../shared/protocol'` 解析到 `protocol/index.ts`；
而 `x.ts` 与目录 `x/` 并存时，`'./x'` 还会指向歧义。

所以全仓统一写成**全路径**：`shared/protocol/index.ts`、`features/skills/index.ts`。

写错的症状很有迷惑性：先报一条 TS2307，紧接着**一大批 TS7006「参数隐式 any」**——因为类型没解析成功，
导入的类型退化成 any，于是所有经由它的回调参数都失去了类型。看到 TS7006 成片出现，
先往回找那条 TS2307。

### 2. 不要在 `src/` 里硬编码 `~/.dsh/...`

所有路径从 `src/shared/paths.ts` 出。测试全部依赖这层间接（每个用例把
`DSH_HOME` / `DSH_AGENTS_HOME` / `DSH_STORE_ROOT` 指向临时目录）。

## 六、构建

`pnpm build` = 两步，**缺一不可**：

```sh
tsc -p tsconfig.build.json   # lib/types/**（声明 + .d.ts.map）
tsdown                       # lib/index.js（host，ESM）+ lib/client.js（client，CJS 包装）
```

只跑 `tsdown` 会让 `lib/types/` 滞后 —— 曾经因此发过一版声明里缺 `reMigrate()` / `activateAll()` 的包。

`tsdown.config.ts` 里两侧半边都开了 `minify`。host 半边开它不只是为了小：拆成小模块后
rolldown 会保留更多恰好可达的 JSDoc 块（旧单文件布局下很多被 DCE 掉了），
不开 minify 产物会从 138.6 kB **涨** 上去；开了之后连 `//#region` 标记一起消失，
降到 49.6 kB（gzip 40.2 → 16.2 kB）。client 半边尺寸则不受拆分影响。

node node_modules/typescript/bin/tsc --noEmit    # 0 错误
node node_modules/vitest/vitest.mjs run          # 9 files / 120 tests
node --check lib/index.js && node --check lib/client.js

判断兼容性时**只比产物、不切依赖版本**：解两个版本的 tgz，比对 `lib/index.js` /
`lib/client.js` 的 sha256，相同即行为字节级一致。切 devDeps 到旧版再 `pnpm install`
会把 `node_modules` 搞坏（pnpm 状态残留让前端包变空链接，满屏 TS2307）。
